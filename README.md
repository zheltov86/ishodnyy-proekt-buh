# ishodnyy-proekt-buh

Дамп расширения **Бухгалтерия (BP)** для проекта ЭдоОбмен.

## Версия

**1.0037**

Исходники расширения по-прежнему лежат на ПК пользователя:

- `ОбменБух12_10_2026`
- `ObmenBP-ZagruzkaVBuh`

Этот репозиторий заменяет тот старый локальный дамп. Файлы конфигурации 1С сюда ещё не выгружены.
